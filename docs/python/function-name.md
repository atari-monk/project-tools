## Python Function Naming Convention

* Use **`snake_case`** for function names.
* Use **lowercase letters** with words separated by underscores.
* Choose clear, descriptive names.
* Avoid abbreviations unless they are well-known.
* Examples:

  * `set_pyright_config()`
  * `load_user_data()`
  * `validate_config()`
  * `get_project_path()`

**Preferred:** `set_pyright_config()`
**Avoid:** `setPyrightConfig()`, `SetPyrightConfig()`
